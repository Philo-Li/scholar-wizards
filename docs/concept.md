# Scholar Wizards 的理念与内容设计

> 本文规定网站要讲什么、选谁、为什么选、每个页面怎么写。改版和以后增补人物、专题，都以本文为准。
>
> 最后更新：2026-11-21

## 1. 灵感来源：Market Wizards

名字和结构都学的是 Jack Schwager 的 *Market Wizards*（《金融怪杰》）系列。这套书访谈了一批长期跑赢市场的交易者，它的好处有三点：

1. **每人一章。** 一章只讲一个人，先交代他凭什么值得一读，再让他用自己的话讲路径、方法和失败。
2. **风格各异。** 有做趋势的，有做反转的；有数学家，有赌徒，有退学生。书不提倡任何一种方法，而是让读者看到，顶尖的人走的路可以完全不同。
3. **最后提炼共性。** 书末有一章 "Market Wizard Lessons"，把几十个人身上共同的东西总结出来，读者可以拿去用。

Scholar Wizards 照这个结构来做科研人物：一个人一章，专题把风格相近或道路相近的人放在一起，最后单独一页总结这些人身上共同的东西。

## 2. 核心理念：不平庸

这是一个展示科研传奇和科研人才的地方。他们的背景、年龄、性格、学科、工作方式可以完全不同，共同点只有一个：**不平庸**。

引用数只是衡量"不平庸"的一种标准，而且有明显的局限：它偏向论文多、合作大的领域，也偏向后半生。下面这些同样是入选的理由：

- 一个想法改变了一个学科（Shannon 1948 年的信息论、Nash 28 页的博士论文）；
- 在常规体制之外做出了一流工作（拉马努金、法拉第、许埈珥）；
- 很晚才做出代表作，或者等了几十年才被承认（张益唐、卡里科、麦克林托克）；
- 跨越多个领域都留下了成果（冯·诺伊曼、司马贺）；
- 用自己的规则做科研，比如拒绝奖项、退出学界（佩雷尔曼、格罗滕迪克）；
- 在没有位置的年代为后来者开了路（诺特、吴健雄、屠呦呦）；
- 年轻一代中已经显示出非凡轨迹的人（数据里 m 商极高的新锐）。

## 3. 入选标准：每个人都要写清"为什么被选中"

每个人物页的第一段就是 **为什么入选**，一到两句话，必须具体到事实，不能写"杰出""伟大"这类空话。

- 好的写法："一个没有学位的马德拉斯港务局职员，寄给哈代的十页公式里有些连哈代也没见过。"
- 不好的写法："他是印度最伟大的数学家之一。"

入选至少满足下面一条，并在页面上标出是哪一条：

| 入选理由 | 说明 |
|---|---|
| 开创 | 提出了一个新领域、新方法或新范式 |
| 非常规路径 | 没有走常规的学历或职位路线 |
| 时间 | 极早或极晚做出代表作，或成果被长期忽视后才被承认 |
| 跨界 | 在两个以上领域有一流贡献 |
| 风骨 | 在名利、体制或压力面前坚持自己的做法 |
| 开路 | 在少有同类的环境里打开局面 |
| 数据 | 引用、h 指数或 m 商在本学科处于顶端（来自 OpenAlex 数据） |

学科数据页里的 2000 多位学者是按引用自动抽取的，他们的页面同样要说明入选原因：属于哪份名单、按什么规则进入、在本学科排第几。

## 4. 专题

专题像期刊的特刊：每个专题有一段导言、明确的入选标准、一组人物，以及一张帮助理解这组人的图。一个人可以出现在多个专题里。首批专题：

| 专题 | 讲什么 |
|---|---|
| 少年成名 | 25 岁前做出代表作的人 |
| 大器晚成 | 50 岁后才做出代表作，或等了很久才被承认 |
| 体制之外 | 自学、转行、没有学位或不在大学里 |
| 跨界者 | 在多个领域都留下了一流成果 |
| 被时间证明 | 当时被否定或忽视，后来被证明是对的 |
| 一个想法 | 一篇论文或一个想法改变了一个学科 |
| 按自己的规则 | 拒绝奖项、远离学界、只做自己认为重要的事 |
| 开路的女性 | 在几乎没有女性位置的年代做出一流工作 |
| 伟大的合作 | 两个人或一个小团队一起做出的成果 |
| 华人科学家 | 华人科研者中的传奇 |
| 数据里的新星 | 从 OpenAlex 数据中找出的、学术轨迹异常陡峭的年轻学者 |

后续增补专题时，先回答两个问题：这组人共同的"不平庸"是什么？读者看完能带走什么？答不出来就不做。

## 5. 人物页的结构

每个人物页像一章 *Market Wizards*，也像英国皇家学会的《会士传记回忆录》（Biographical Memoirs）。顺序固定：

1. **姓名、生卒年、学科、肖像。** 肖像来自 Wikimedia Commons，标注作者和许可。
2. **为什么入选。** 一到两句话，并标出入选理由（见第 3 节）。
3. **生平。** 三到五句话的概述，加一条按年份排列的时间线，每条注明当时的年龄。
4. **性格与工作方式。** 他怎么工作、怎么想问题、有什么怪癖。每条都要有出处可查。
5. **代表作。** 两到四项，说明它为什么重要。
6. **用他自己的话。** 只引用在公开访谈、演讲、自传中能查到原文的话，并附出处。查不到原文就不引用。
7. **访谈与报道。** 真实存在的访谈、口述史、纪录片、深度报道、讣告的链接，每条注明媒体和年份。
8. **可以借鉴的地方。** 一到三条，读者能拿去用的做法。
9. **数据档案。** 如果他在 OpenAlex 数据里，链接到对应的学者数据页。

## 6. 共性总结页

对应 *Market Wizards* 书末的 "Lessons" 一章。从所有人物里归纳出反复出现的特点，例如：选一个真正重要的问题、长期专注、敢于离开主流、找到对的合作者、把失败当作信息。每一条都链接到体现它的人物。

## 7. 内容准确性

这是一个给学者和科研人员看的网站，错一个事实就会失去信任：

- **不编造。** 不写查不到出处的事实、引语和链接。
- **链接必须能打开。** 每条外部链接在入库前都要实际请求一次，确认能打开且内容对得上。
- **引语必须有原文。** 只用能在访谈、演讲、自传原文中找到的话，并注明出处。常见的误传名言不用。
- **生卒年、奖项等结构化事实** 从 Wikidata 自动获取，不手写。
- **图片** 只用 Wikimedia Commons 上许可明确的图片，并标注作者和许可。
- 访谈不是我们做的：所有"访谈"都是指向公开访谈的链接和摘要，不冒充原创访谈。

## 8. 设计原则

- 延续现在的学术排版风格：衬线正文、编号图、图注、三线表。
- 人物页是读的，不是查的：长文排版，一屏只讲一件事，不堆数字。
- 引用指标退到"数据档案"里，作为了解一个人的一个角度，不放在最前面。
- 每张图都要回答一个具体问题，例如"他们做出代表作时多大""从做出成果到获奖等了多久"。

## 9. 和学科数据的关系

原有的十个学科数据页、2000 多个学者数据页和方法页保留不动，作为"数据视角"。人物页里的人如果在数据里，两边互相链接。"数据里的新星"专题直接从数据中挑人，是两部分之间的桥。
